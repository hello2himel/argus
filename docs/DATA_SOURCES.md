# Data sources
- Sentinel-2 L2A via Microsoft Planetary Computer STAC https://planetarycomputer.microsoft.com/api/stac/v1 collection sentinel-2-l2a. Free, 10m VNIR, ~5-day revisit (clouds permitting). Search keyless; blobs need auto-SAS.
- Sentinel-1 GRD (cloudy complement), Landsat 8/9 (history) — same STAC pattern.
- Boundaries: Bangladesh Forest Dept https://bforest.gov.bd, MoEFCC http://moef.gov.bd, BWDB https://en.bwdb.gov.bd/rivers-information (authoritative, request/fee); Protected Planet https://www.protectedplanet.net/country/BGD (reference, non-commercial, generalized); OSM/Geofabrik https://download.geofabrik.de/asia/bangladesh.html (ODbL, crowd-sourced).
